Master's thesis · 2025/26

Auto Safety Pro

Hybrid search and grounded summaries over U.S. vehicle recalls and complaints.

Problem. NHTSA's search is keyword based. A query for "brakes fail in the wet" misses the owner who wrote "pedal goes soft in the rain".

Approach. BM25 keeps exact part names precise. Sentence embeddings catch the same meaning in different words. A weighted fusion ranks both, and only the top 10 records go to Flan-T5 for a summary, so every answer links back to evidence.

Learned. Hybrid beat either method alone, and grounding mattered more than model size. Evaluating without gold labels is hard, so I measured with P@10, R@10, MRR and nDCG on test queries.

Deepfake Video Detection

A video classifier that checks faces frame by frame, with a Django front end.

Problem. Manipulated faces are hard to spot, and a detector has to hold up on data it has not seen.

Approach. OpenCV and face detection crop faces from sampled frames. A ResNeXt network extracts features per frame and an LSTM reads the sequence to decide real or fake.

Learned. Fewer frames cost accuracy, so the frame budget is a real design choice, and a result on one dataset does not carry over to another.
